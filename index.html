TagTuner: a local Etsy listing SEO audit — see what your tags, title and description are missing

A one-time-purchase tool ($19) that runs entirely on your machine: paste a listing's title, 13 tags, description, category and attributes, and get a 0–100 SEO hygiene score from 19 rule checks across 5 weighted dimensions, each graded pass / warn / fail with concrete fix suggestions. The MVP is built and tested; it is not on sale yet. This page answers one question: at $19 one-time, is it worth launching.

Why validate first

  • The incumbents, eRank and Marmalead, are full-featured subscription keyword-research tools: eRank has a free tier plus $5.99 / $9.99 / $29.99 per month plans; Marmalead starts at $19 per month with no free tier (pricing checked October 2026).
  • TagTuner is deliberately different, in one sentence: it runs locally and your listing data is never uploaded, and it is a one-time purchase that does "rule auditing" — not "search-volume estimation". Etsy does not publish real search-volume data; everything rivals call "search volume" is an estimate, and TagTuner honestly does not do that.
  • Honest limitations, stated up front: (1) the checks are heuristic rules derived from Etsy's public seller guidance, and have not been validated against real Etsy search rankings — the score measures listing hygiene, not traffic potential; (2) Etsy does not show tags on public listing pages, so tags must be pasted by the seller (only you can see your own tags in the shop backend); (3) direct fetching from datacenter IPs gets blocked by Etsy's anti-bot checks — the tool degrades gracefully to paste mode and does not attempt any bypass.

What it checks (built, tested, not yet for sale)

  • 19 rule checks across 5 weighted dimensions: Tags (30%) — all 13 tag slots used, each tag within the character limit, multi-word phrases preferred, no duplicate root words; Title (25%) — length within the 140-character limit, keyword features front-loaded, no subjective words; Description (20%) — content depth, core keywords in the first ~160 characters shown in search preview; Attributes (15%) — completeness of attributes and materials; Category (10%) — most specific subcategory selected
  • 0–100 score with pass / warn / fail per rule, each with a concrete, actionable fix suggestion
  • Pure Python standard library, runs locally — no third-party dependencies, no login, no paid APIs, no server

Tested on 5 real public listings with reproducible scores: handmade clay mug 77, pink novelty mug 74, ceramic tumbler 85 (duplicate-tag check fired), stoneware coffee cup 81 (single-word-tag issue fired), mandala mug 56 (multiple fails on title/description/attributes). Title/description/attributes come from live public pages; tags are seller-perspective test data, disclosed as such, since Etsy does not publish real tags.

FAQ

Can I buy it now?
No. It's built but not on sale; this page is all there is.

Does registering obligate me to buy?
No. Registration only means "notify me when it launches"; you decide after seeing the finished product.

Will a high score get my listing more traffic?
No. The tool checks whether your listing follows Etsy's public writing guidance; it is not a ranking predictor and was not validated against real search rankings.

Does it estimate search volume or competition?
No. Etsy does not publish real search volume; the incumbents' numbers are estimates. TagTuner deliberately only does rule auditing, honestly labeled.

Why not just use eRank's free tier?
eRank's free tier is genuinely capable (5 audits per day). TagTuner is for sellers who want a one-time purchase, local-only processing with no shop connection, and an honest audit scope.
